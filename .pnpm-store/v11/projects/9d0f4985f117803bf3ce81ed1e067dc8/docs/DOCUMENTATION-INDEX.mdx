# Documentation Index

The documentation index is a searchable map of every learning track and focused
topic page. Use it when you know the domain but not the canonical page; use the
[learning path](reference/LEARNING-PATH.mdx) when you need prerequisite order.

## Page Overview

- **Overview pages** define the domain and briefly map every child topic.
- **Focused guides** teach one concept from definition through examples and
  production boundaries.
- **Deep dives** explain internals and assume linked prerequisites.
- **Runbooks and labs** turn knowledge into diagnosis or executable evidence.
- **Interview pages** test reasoning after the canonical teaching pages.

Search by the concept's common name. Visible titles are kept concise even where
legacy filenames remain stable to preserve public links.

For authoring rules and page-type definitions, open the
[documentation guide](reference/DOCUMENTATION-GUIDE.md).
