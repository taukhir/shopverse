## How To Use A Questionnaire

1. Start with the highest-priority prompts and answer them without notes.
2. Use the linked canonical documentation to strengthen internals, failure handling and trade-offs.
3. Treat source-occurrence fields only as evidence from that source; do not present them as verified employer statistics.
4. Use the [Lead And Architect Preparation Dashboard](./leadership/interview-program/LEAD-ARCHITECT-PREPARATION-DASHBOARD.md)
   for study sequencing, mocks and readiness decisions.
