# Interview Practice Dashboard

The dashboard turns completed MCQ sessions into local preparation evidence. It calculates
subject accuracy, role readiness, weak-topic review dates, a recent-attempt history, and a
recommended mock sequence.

<InterviewPracticeDashboard />

## Privacy And Portability

Progress remains in this browser's local storage. The application records subject, difficulty,
aggregate score, elapsed time, completion time, and topic-level correct/total counts. It does
not retain selected answers, question text, identity, credentials, or personal profile data.

Use **Export** before clearing browser data or moving devices. **Import** accepts only a
ShopVerse practice JSON structure and caps retained history at 500 attempts. **Reset** asks for
confirmation before deleting the local history.

## Readiness Interpretation

The role gate requires at least two attempts and 80% aggregate accuracy in every core subject.
This proves repeatable retrieval only. Complete system-design, incident, behavioral, coding,
and machine-coding mocks before treating the role as interview-ready.
