<a id="shared-161eb0540510"></a>

The catalog generator is tools/build_fulfillment_catalog.py (local reference: `tools/build_fulfillment_catalog.py`). Run with Python 3 and PyYAML, optionally `--dependencies PATH` for a separate package directory. It reads source/contracts and rewrites the three generated catalog files; it does not call application endpoints or modify application code.

<a id="shared-a34941af1a7d"></a>

All findings are static source/configuration inspection. They do not establish deployed values, measured latency or successful external integration behavior. Missing external implementations are listed explicitly in the reverse-engineering reference.
